# Blue Fission GitHub profile

This repository maintains Blue Fission's GitHub organization profile. The public-facing text lives in [profile/README.md](profile/README.md).

Propose changes to that file through a pull request. Once reviewed and merged into the default branch, GitHub can display it on the [organization overview](https://github.com/BlueFissionTech) when this repository is public.

The organization's short description, website, and contact details are separate GitHub settings and are not changed by this README.
