# Blue Fission

Blue Fission develops web applications and software services, with work in service integration, automation, and machine learning.

Our public repositories share reusable parts of that work:

- [DevElation](https://github.com/BlueFissionTech/develation) provides PHP primitives and service utilities.
- [Automata](https://github.com/BlueFissionTech/automata) provides PHP components for automation and machine learning.
- [BlueCore](https://github.com/BlueFissionTech/bluecore) contains application framework components.
- [Opus](https://github.com/BlueFissionTech/opus) is an application framework and platform under development.

Check each repository's license, current release, compatibility, and support terms before adopting it. Public source access does not establish production readiness for every capability.

Learn more at [bluefission.com](https://bluefission.com) or contact [technical@bluefission.com](mailto:technical@bluefission.com).
